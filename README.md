# Umbra

Особиста колекція фільмів, серіалів та ігор: оцінки, нотатки, «Хочу подивитися», відстеження серіалів, статистика, друзі та підбір «що подивитися ввечері» зі ШІ. Є застосунок для Android TV та команди з телефона на телевізор.

Каталог відкривається тільки після входу: без акаунта будь-яка адреса веде на екран входу, а після входу користувач повертається на запитану сторінку. Дані належать акаунту Firebase і синхронізуються між пристроями.

Це самостійний репозиторій та застосунок, не частина CodeQuest.

## Запуск

Node.js 22.12+ (версія для CI в `.nvmrc`):

```sh
npm ci
npm run dev
```

Production-збірка: `npm run build && npm run preview`.

Ключі TMDB та OMDb у вихідному коді не зберігаються: збірка бере їх зі змінних репозиторію `TMDB_KEY`, `OMDB_KEY` та адресу сервера з `API_URL` (GitHub → Settings → Secrets and variables → Actions → **Variables**) як `VITE_TMDB_KEY`, `VITE_OMDB_KEY`, `VITE_API_URL`. Ключі клієнтських API — не секрет: вони все одно потрапляють у браузер. Для локальної розробки — `.env.local` (у `.gitignore`):

```sh
VITE_TMDB_KEY=ваш_ключ_tmdb
VITE_OMDB_KEY=ваш_ключ_omdb
```

## Перевірки

```sh
npm test            # юніт-тести сайту та сервера (vitest)
npm run test:rules  # правила Firestore на емуляторі
npm run build
npm run test:e2e    # Playwright на емуляторах Auth/Firestore
```

Емуляторам Firebase потрібна Java 21; браузерам — `npx playwright install chromium`. Тести працюють із локальними емуляторами та підміняють TMDB, OMDb і сервер — робоча база не використовується.

## Акаунт та особисті дані

- Вхід: email/пароль і Google; на телевізорі — QR-код з телефона або Google-акаунт телевізора. Стан входу береться тільки з Firebase observer.
- Документи: `users/{uid}/library/{movie|tv}-{tmdbId}` (фільми та серіали), `users/{uid}/games/{igdbId}` (ігри), `users/{uid}/links/steam`; друзі — нижче.
- `onSnapshot` надає актуальну колекцію, включно з вилученнями; дані іншого користувача ніколи не змішуються з поточними (`SessionState` перестворюється під час зміни акаунта).
- Firestore з IndexedDB-кешем зберігає чергу offline-змін. Зміни відправляються окремими полями; час оновлення призначає сервер.
- Чернетка коментаря до оцінки (фільму чи гри) зберігається на пристрої до «Підтвердити» або «Скасувати» — закрита шторка її не втрачає (`src/lib/drafts.ts`, окремо для кожного акаунта).
- Старі локальні дані не переносяться в хмару автоматично: чиї вони — невідомо. Стара полиця фільмів `umbra.library` не використовується; ігри старої версії (`umbra.gamesLibrary`) переносяться в акаунт лише кнопкою в «Профіль та налаштування».
- Резервна копія («Профіль та налаштування» → «Резервна копія»): один JSON із фільмами, серіалами та іграми. Імпорт перевіряє кожен запис, додає та оновлює, не вилучає решту; записує пакетами по 100, після збою його можна повторити. Старі копії без ігор також підтримуються.

Firebase web-конфігурація публічна; захист — у `firestore.rules`: тільки власник і тільки валідні поля. **CI правила не публікує** — після їхньої зміни:

```sh
npx firebase deploy --only firestore:rules --project umbra-18ba8
```

Правила з новими полями публікуються раніше за сайт, який їх записує, інакше такі записи сервер відхилить.

## Фільми та серіали

- **Головна** (`src/pages/Home.tsx`): персональний банер (`src/lib/spotlight.ts`) — найближчий реліз із «Хочу подивитися», нова серія серіалу з колекції, рекомендація за найкращою оцінкою або популярна новинка; ряди «Продовжити дивитися», релізи з «Хочу подивитися» та добірки.
- **Релізи** (`src/lib/releases.ts`): фільми — перший публічний реліз у регіоні; серіали — прем'єра серіалу, нового сезону або продовження сезону після перерви понад 45 днів («Частина 2»). Вікно — 7 днів уперед і назад.
- **Картка** (`src/pages/Title.tsx`, блоки в `src/components/TitleDetails.tsx`): один запит TMDB з `append_to_response` плюс OMDb. Рейтинги IMDb (Agregarr), TMDB, Rotten Tomatoes і Metascore (OMDb, запасне джерело — Wikidata), нагороди, де дивитися (JustWatch через TMDB), відео, кадри, актори та знімальна група, подробиці, рецензії, франшиза, рекомендації. На телефоні — кнопка «На телевізорі в Lampa».
- **Серіали**: статуси «Дивлюся» та «Покинуто», прогрес — остання переглянута серія (`src/lib/tracking.ts`). Для IMDb-рейтингів серій їхні id запитуються по три за раз і зберігаються на пристрої.
- **Пошук** (`src/pages/Search.tsx`): у міру введення, фільтри, виправлення розкладки; пошук назв (`findTitles`) спільний з ТБ.
- **Колекція** (`src/lib/collection.ts`): пошук, статус, тип, жанр, оцінка, десятиліття, сортування — в адресі сторінки. Жанри та тривалість — з TMDB, кеш на пристрої на 30 днів (`src/lib/meta.ts`).
- **Гід** (`/guide`): добірки за жанрами та десятиліттями; у серіалів свої id жанрів (`genreIds` у `src/lib/search.ts`).
- **Статистика** (`/stats`, `src/lib/stats.ts`): лічильники, години, оцінки, жанри, десятиліття, найкраще, підсумки року. Окремої дати перегляду немає — рік рахується за останньою відміткою. Покинуті тайтли не входять до кількості фільмів та серіалів, але їхні години враховуються.
- **На вечір** (`/tonight`): швидкий підбір за відповідями (`src/lib/useQuickTonight.ts`) або чотири питання Claude і добірка з урахуванням усієї колекції (`src/lib/useAiTonight.ts`, сервер — `/ai/tonight`).

This product uses the TMDB API but is not endorsed or certified by TMDB.

## Ігри

IGDB — каталог, OpenCritic і Steam — оцінки, IsThereAnyDeal — ціни, Xbox Game Pass — передплата; ключі на сервері. Колекція ігор у хмарі (`src/lib/gameStore.ts`): статуси, платформи, оцінки, години; підключення Steam імпортує бібліотеку з годинами та список бажаного. Докладніше про джерела — `docs/game-data.md`.

## Друзі

- `profiles/{uid}` — ім'я та фото для запрошень; читається за ID тими, хто ввійшов, перерахувати не можна.
- Запрошення `#/friends/invite/{uid}`: одержувач додає автора запрошення в `users/{me}/friends` і створює заявку `users/{them}/requests/{me}`; після «Прийняти» дружба взаємна.
- Друзям видно копію полиці фільмів та серіалів без нотаток: `profiles/{uid}/ratings/{type-id}`, тільки тим, кого власник додав у друзі. Ігри друзям поки що не видно.
- `FriendsIndexProvider` завантажує полиці друзів (не частіше ніж раз на 2 хвилини): позначки на постерах, рядки в колекції, «Оцінки друзів» у картці.

## Телевізор

- Сайт у режимі `?tv=1` — власні екрани для пульта (`src/tv/`): стрічка, пошук з екранною клавіатурою та голосом, «На вечір», колекція, картка з тією самою інформацією, що на телефоні. Фокус — рушій смуг `src/tv/lanes.ts`; анімації тільки через transform/opacity.
- Застосунок `android-tv/` — WebView з мостом `window.UmbraTV`: голос, вхід через Google телевізора, запуск стрімінгів та Lampa, push-команди. Збірка та підпис — у GitHub Actions, встановлення через Downloader (код **2351637** → останній реліз).
- Вхід на ТБ: QR-код підтверджується на телефоні (`worker/src/tvLogin.ts`).
- «На телевізорі в Lampa»: телефон → сервер → push (FCM) → телевізор будить екран і відкриває фільм у Lampa (`worker/src/tvRemote.ts`, `android-tv/…/Remote.kt`).

## Сервер (Cloudflare Worker)

`worker/` тримає ключі та звертається до сервісів, недоступних із браузера. Відповідає тільки сайтам з `ALLOWED_ORIGINS` (`worker/wrangler.toml`), крім `/health` та сторінок `/s/…`.

| Маршрут                                                                     | Що робить                                                               |
| --------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `GET /health`                                                               | які сервіси підключені (так/ні)                                         |
| `POST /igdb/:endpoint`                                                      | запити IGDB; токен Twitch оновлюється автоматично; кеш від години до тижня |
| `GET /twitch/top-games`                                                     | що дивляться на Twitch                                                  |
| `GET /opencritic`, `/prices`, `/deals`, `/gamepass/:list`, `/steam/app/:id` | оцінки, ціни, знижки, Game Pass, сторінка Steam                         |
| `GET /steam/user/:steamId/profile\|library\|achievements/:appId`            | дані Steam користувача — **тільки для авторизованих** (Firebase ID token) |
| `POST /steam/verify`                                                        | перевірка входу через Steam (OpenID)                                     |
| `POST /ai/tonight`                                                          | питання та добірка Claude — для авторизованих, із денними лімітами      |
| `POST /tv/code`, `GET /tv/code/:code`, `POST /tv/confirm`, `POST /tv/token` | вхід на ТБ за QR                                                        |
| `POST /tv/device`, `GET /tv/devices`, `POST /tv/open`                       | телевізори акаунта та команди на них                                    |
| `GET /s/movie\|tv\|game/:id`, `/s/invite/:uid`                              | сторінки для прев'ю посилань у месенджерах                              |

Стан — у Durable Objects: коди входу (`TvPairing`), телевізори акаунта (`TvRemote`), денні ліміти (`UsageCounter`: бюджет ШІ на людину та загальний, коди ТБ, команди на ТБ — атомарно й один лічильник на весь світ).

**Secrets** репозиторію: `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, `TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET`, `ITAD_API_KEY`, `OPENCRITIC_API_KEY`, `STEAM_API_KEY`, `ANTHROPIC_API_KEY`, `FIREBASE_SERVICE_ACCOUNT` (підписує вхід на ТБ та відправляє push). Змінні у `wrangler.toml`: `AI_MODEL` (порожньо — модель за замовчуванням), `AI_DAILY_LIMIT`, `AI_GLOBAL_LIMIT`, `AI_USERS`.

Локально: `cd worker && npx wrangler dev` (ключі — у `worker/.dev.vars`, у `.gitignore`; `AUTH_EMULATOR=true` приймає токени емулятора).

## Оновлення та PWA

Production-артефакт — `dist`, публікується workflow після merge у main (GitHub Pages: Source — GitHub Actions). Service worker зберігає узгоджений комплект HTML/JS/CSS і перевіряє оновлення під час повернення в застосунок; нова версія встановлюється кнопкою «Оновити» (на телевізорі — автоматично). Номер збірки — короткий Git SHA. Кешуються оболонка та до 200 постерів; дані Firebase через service worker не йдуть.

## Сповіщення

Push на телефон поки не відправляються (є тільки команди на телевізор). Для сповіщень про релізи знадобляться підписки зі згодою, часовий пояс, серверна перевірка дат за розкладом та журнал відправлень — не з браузера.
