# Umbra

Личная коллекция фильмов, сериалов и игр: оценки, заметки, «Хочу посмотреть», отслеживание сериалов, статистика, друзья и подбор «что посмотреть вечером» с ИИ. Есть приложение для Android TV и команды с телефона на телевизор.

Каталог открывается только после входа: без аккаунта любой адрес ведёт на экран входа, а после входа пользователь возвращается на запрошенную страницу. Данные принадлежат аккаунту Firebase и синхронизируются между устройствами.

Это самостоятельный репозиторий и приложение, не часть CodeQuest.

## Запуск

Node.js 22.12+ (версия для CI в `.nvmrc`):

```sh
npm ci
npm run dev
```

Production-сборка: `npm run build && npm run preview`.

Ключи TMDB и OMDb в исходниках не хранятся: сборка берёт их из переменных репозитория `TMDB_KEY`, `OMDB_KEY` и адрес сервера из `API_URL` (GitHub → Settings → Secrets and variables → Actions → **Variables**) как `VITE_TMDB_KEY`, `VITE_OMDB_KEY`, `VITE_API_URL`. Ключи клиентских API — не секрет: они всё равно попадают в браузер. Для локальной разработки — `.env.local` (в `.gitignore`):

```sh
VITE_TMDB_KEY=ваш_ключ_tmdb
VITE_OMDB_KEY=ваш_ключ_omdb
```

## Проверки

```sh
npm test            # юнит-тесты сайта и сервера (vitest)
npm run test:rules  # правила Firestore на эмуляторе
npm run build
npm run test:e2e    # Playwright на эмуляторах Auth/Firestore
```

Эмуляторам Firebase нужна Java 21; браузерам — `npx playwright install chromium`. Тесты работают с локальными эмуляторами и подменяют TMDB, OMDb и сервер — рабочая база не используется.

## Аккаунт и личные данные

- Вход: email/пароль и Google; на телевизоре — QR-код с телефона или Google-аккаунт телевизора. Состояние входа берётся только из Firebase observer.
- Документы: `users/{uid}/library/{movie|tv}-{tmdbId}` (фильмы и сериалы), `users/{uid}/games/{igdbId}` (игры), `users/{uid}/links/steam`; друзья — ниже.
- `onSnapshot` даёт актуальную коллекцию, включая удаления; данные другого пользователя никогда не смешиваются с текущими (`SessionState` пересоздаётся при смене аккаунта).
- Firestore с IndexedDB-кэшем хранит очередь offline-изменений. Изменения отправляются отдельными полями; время обновления ставит сервер.
- Черновик комментария к оценке (фильма или игры) хранится на устройстве до «Подтвердить» или «Отмена» — закрытая шторка его не теряет (`src/lib/drafts.ts`, отдельно для каждого аккаунта).
- Старые локальные данные не переносятся в облако сами: чьи они — неизвестно. Старая полка фильмов `umbra.library` не используется; игры старой версии (`umbra.gamesLibrary`) переносятся в аккаунт только кнопкой в «Профиль и настройки».
- Резервная копия («Профиль и настройки» → «Резервная копия»): один JSON с фильмами, сериалами и играми. Импорт проверяет каждую запись, добавляет и обновляет, не удаляет остальные; пишет пакетами по 100, после сбоя его можно повторить. Старые копии без игр тоже принимаются.

Firebase web-конфигурация публичная; защита — в `firestore.rules`: только владелец и только валидные поля. **CI правила не публикует** — после их изменения:

```sh
npx firebase deploy --only firestore:rules --project umbra-18ba8
```

Правила с новыми полями публикуются раньше сайта, который их пишет, иначе такие записи сервер отклонит.

## Фильмы и сериалы

- **Главная** (`src/pages/Home.tsx`): персональный баннер (`src/lib/spotlight.ts`) — ближайший релиз из «Хочу посмотреть», новая серия сериала из коллекции, рекомендация по лучшей оценке или популярная новинка; ряды «Продолжить смотреть», релизы из «Хочу посмотреть» и подборки.
- **Релизы** (`src/lib/releases.ts`): фильмы — первый публичный релиз в регионе; сериалы — премьера сериала, нового сезона или продолжение сезона после перерыва дольше 45 дней («Часть 2»). Окно — 7 дней вперёд и назад.
- **Карточка** (`src/pages/Title.tsx`, блоки в `src/components/TitleDetails.tsx`): один запрос TMDB с `append_to_response` плюс OMDb. Рейтинги IMDb (Agregarr), TMDB, Rotten Tomatoes и Metascore (OMDb, запасной источник — Wikidata), награды, где смотреть (JustWatch через TMDB), видео, кадры, актёры и группа, подробности, рецензии, франшиза, рекомендации. На телефоне — кнопка «На телевизоре в Lampa».
- **Сериалы**: статусы «Смотрю» и «Бросил», прогресс — последняя просмотренная серия (`src/lib/tracking.ts`). Для IMDb-рейтингов серий их id запрашиваются по три за раз и хранятся на устройстве.
- **Поиск** (`src/pages/Search.tsx`): по мере набора, фильтры, исправление раскладки; поиск названий (`findTitles`) общий с ТВ.
- **Коллекция** (`src/lib/collection.ts`): поиск, статус, тип, жанр, оценка, десятилетие, сортировка — в адресе страницы. Жанры и длительность — из TMDB, кэш на устройстве на 30 дней (`src/lib/meta.ts`).
- **Гид** (`/guide`): подборки по жанрам и десятилетиям; у сериалов свои id жанров (`genreIds` в `src/lib/search.ts`).
- **Статистика** (`/stats`, `src/lib/stats.ts`): счётчики, часы, оценки, жанры, десятилетия, лучшее, итоги года. Отдельной даты просмотра нет — год считается по последней отметке. Брошенные тайтлы не входят в число фильмов и сериалов, но их часы считаются.
- **На вечер** (`/tonight`): быстрый подбор по ответам (`src/lib/useQuickTonight.ts`) или четыре вопроса Claude и подборка с учётом всей коллекции (`src/lib/useAiTonight.ts`, сервер — `/ai/tonight`).

This product uses the TMDB API but is not endorsed or certified by TMDB.

## Игры

IGDB — каталог, OpenCritic и Steam — оценки, IsThereAnyDeal — цены, Xbox Game Pass — подписка; ключи на сервере. Коллекция игр в облаке (`src/lib/gameStore.ts`): статусы, платформы, оценки, часы; подключение Steam импортирует библиотеку с часами и список желаемого. Подробнее об источниках — `docs/game-data.md`.

## Друзья

- `profiles/{uid}` — имя и фото для приглашений; читается по ID вошедшими, перечислить нельзя.
- Приглашение `#/friends/invite/{uid}`: получатель добавляет приглашающего в `users/{me}/friends` и создаёт заявку `users/{them}/requests/{me}`; после «Принять» дружба взаимная.
- Друзьям видна копия полки фильмов и сериалов без заметок: `profiles/{uid}/ratings/{type-id}`, только тем, кого владелец добавил в друзья. Игры друзьям пока не видны.
- `FriendsIndexProvider` загружает полки друзей (не чаще раза в 2 минуты): значки на постерах, строки в коллекции, «Оценки друзей» в карточке.

## Телевизор

- Сайт в режиме `?tv=1` — свои экраны для пульта (`src/tv/`): лента, поиск с экранной клавиатурой и голосом, «На вечер», коллекция, карточка с той же информацией, что на телефоне. Фокус — движок полос `src/tv/lanes.ts`; анимации только через transform/opacity.
- Приложение `android-tv/` — WebView с мостом `window.UmbraTV`: голос, вход через Google телевизора, запуск стримингов и Lampa, push-команды. Сборка и подпись — в GitHub Actions, установка через Downloader (код **2351637** → последний релиз).
- Вход на ТВ: QR-код подтверждается на телефоне (`worker/src/tvLogin.ts`).
- «На телевизоре в Lampa»: телефон → сервер → push (FCM) → телевизор будит экран и открывает фильм в Lampa (`worker/src/tvRemote.ts`, `android-tv/…/Remote.kt`).

## Сервер (Cloudflare Worker)

`worker/` держит ключи и обращается к сервисам, недоступным из браузера. Отвечает только сайтам из `ALLOWED_ORIGINS` (`worker/wrangler.toml`), кроме `/health` и страниц `/s/…`.

| Маршрут                                                                     | Что делает                                                              |
| --------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| `GET /health`                                                               | какие сервисы подключены (да/нет)                                       |
| `POST /igdb/:endpoint`                                                      | запросы IGDB; токен Twitch обновляется сам; кэш от часа до недели       |
| `GET /twitch/top-games`                                                     | что смотрят на Twitch                                                   |
| `GET /opencritic`, `/prices`, `/deals`, `/gamepass/:list`, `/steam/app/:id` | оценки, цены, скидки, Game Pass, страница Steam                         |
| `GET /steam/user/:steamId/profile\|library\|achievements/:appId`            | данные Steam пользователя — **только для вошедших** (Firebase ID token) |
| `POST /steam/verify`                                                        | проверка входа через Steam (OpenID)                                     |
| `POST /ai/tonight`                                                          | вопросы и подборка Claude — для вошедших, с дневными лимитами           |
| `POST /tv/code`, `GET /tv/code/:code`, `POST /tv/confirm`, `POST /tv/token` | вход на ТВ по QR                                                        |
| `POST /tv/device`, `GET /tv/devices`, `POST /tv/open`                       | телевизоры аккаунта и команды на них                                    |
| `GET /s/movie\|tv\|game/:id`, `/s/invite/:uid`                              | страницы для превью ссылок в мессенджерах                               |

Состояние — в Durable Objects: коды входа (`TvPairing`), телевизоры аккаунта (`TvRemote`), дневные лимиты (`UsageCounter`: бюджет ИИ на человека и всего, коды ТВ, команды на ТВ — атомарно и один счётчик на весь мир).

**Secrets** репозитория: `CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, `TWITCH_CLIENT_ID`, `TWITCH_CLIENT_SECRET`, `ITAD_API_KEY`, `OPENCRITIC_API_KEY`, `STEAM_API_KEY`, `ANTHROPIC_API_KEY`, `FIREBASE_SERVICE_ACCOUNT` (подписывает вход на ТВ и отправляет push). Переменные в `wrangler.toml`: `AI_MODEL` (пусто — модель по умолчанию), `AI_DAILY_LIMIT`, `AI_GLOBAL_LIMIT`, `AI_USERS`.

Локально: `cd worker && npx wrangler dev` (ключи — в `worker/.dev.vars`, в `.gitignore`; `AUTH_EMULATOR=true` принимает токены эмулятора).

## Обновления и PWA

Production-артефакт — `dist`, публикуется workflow после merge в main (GitHub Pages: Source — GitHub Actions). Service worker хранит согласованный комплект HTML/JS/CSS и проверяет обновления при возвращении в приложение; новая версия ставится кнопкой «Обновить» (на телевизоре — сама). Номер сборки — короткий Git SHA. Кэшируются оболочка и до 200 постеров; данные Firebase через service worker не идут.

## Уведомления

Push на телефон пока не отправляются (есть только команды на телевизор). Для уведомлений о релизах понадобятся подписки с согласием, часовой пояс, серверная проверка дат по расписанию и журнал отправок — не из браузера.
